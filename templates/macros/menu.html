{# Navigation macros, shared by the page layout and the menu tile. #} {# The items of one menu tree, each with the items under it as a nested list. `links` is a list of {title, path, active, children}; `prefix` is the BEM block of the item, link and child list classes, so the page nav and a tile style their own. `active` is set by the kernel (the page is the link's page or one under it), so it is printed here, never recomputed. #} {% macro items(links, prefix) %} {%- for link in links %}
  • {{ link.title }} {%- if link.children %}
      {{ self::items(links=link.children, prefix=prefix) }}
    {%- endif %}
    • {%- endfor %} {% endmacro %}
