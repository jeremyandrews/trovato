## Design decisions worth remembering if resuming
- LanguageSource carried via response extensions (not just request) because
  edge_cache sits OUTSIDE negotiate_language in the middleware stack; request
  extensions set deep in the stack don't survive back out through next.run().
  Exactly mirrors how track_request_timing gets its RequestProfileSnapshot
  back via response.extensions_mut().
- cache::purge's PENDING set is a plain process-wide static (not
  Redis-backed): a CLI process (config import, cache clear) never runs the
  drain loop, so purge() calls made there are naturally inert — satisfies the
  "no purge from command-line writes" out-of-scope requirement without special
  casing.
- SiteConfig::set/delete purge hook skips RUNTIME_STATE_KEYS and any key
  starting with "plugin." (the variables-host namespace), rather than hooking
  menu::invalidate_config_menus() (which is also called from config import —
  would have violated the "no purge from command-line writes" rule). Menu
  link / URL alias purges are instead hooked directly in
  services::menu_link / services::url_alias (the admin-facing service layer),
  not the lower models/ layer that config import also uses.
- drain_cache_purge_now() is a real (non-test-only) CronService method: used
  by the 1s background task (main.rs), the admin purge-everything button
  (immediate drain), AND tests. Originally planned as #[doc(hidden)]
  "for tests" per the prompt's literal wording, but that undersold its real
  production use by the admin route — removed the doc(hidden) framing.
- Every TestApp build (common/mod.rs) unconditionally seeds "it"/"he"
  languages (seed_test_languages), so the shared test fixture is ALWAYS
  multi-language. Tests needing a "public, single-language-site-default"
  case are not really possible without disrupting other parallel tests in
  the same DB — worked around by using the `/it/` URL prefix for every
  "public eligible" assertion (UrlPrefix source is always public regardless
  of language count), and test (f) explicitly contrasts bare vs /it/ prefix
  on the same fixture.
